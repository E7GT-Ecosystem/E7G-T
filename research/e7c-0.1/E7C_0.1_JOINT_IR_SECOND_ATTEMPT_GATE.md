## Typed local transition

`E7CJointIRSecondAttempt.lean` defines `IRStep` at the successful first-child
boundary: zero fuel stops; positive fuel charges the second attempt and sets
`secondStarted` before checking ledger capacity; zero capacity stops without
an appended event or partial partition; positive capacity appends precisely
the second-attempt event and continues according to the second policy. The
blocked transition theorem proves a charged step, unchanged ordered ledger,
`secondStarted = true` and the model resource-limit observation. The append
theorem supplies a derivation with one ordered second-attempt event. These
theorems quantify over the encoded Lean rows, excluded rows, prior ledger,
steps, policy and remaining resources at this boundary. They do not erase
the earlier exact signed rational rows.

`AdequateIRSecondStep` names the **unproved** premise that a normal run of
the pinned actual `e7_ir_eecq_two_stage_b1.execute` second-attempt block
has a derivation in `IRStep`. `adequate_blocked_observation` is conditional
on this premise. The selected AST checker pins the full executor and checks
that the child call, success guard, charge, started assignment, ledger guard
and event append occur in order. The runtime regression independently runs
source and IR with a `-2/3` Joint row, step bound 4 and ledger bound 2. Both
emit the same charged second-attempt trace; the last ledger has two events,
progress records three steps, no success value is returned, and the source
witness records `second_started = true`. This is finite code evidence, not a
verified CPython-to-`IRStep` translation.

## Separate package bounds

The actual outer `lower` invokes nested `lower_first` before its own
`parse(serialize(package))`. Both actual serializers check their own
`MAX_BYTES = 1_000_000` with `len(encoded) > MAX_BYTES`. Under stable
bindings, no mutation, normal execution, and the specified CPython byte
length/branch semantics, successful nested serialization entails the
**nested** canonical bytes length ≤ 1,000,000; successful outer serialization
entails the **outer** canonical bytes length ≤ 1,000,000. A successful outer
`lower` thus passes both checks; neither bound follows from source admission
and the nested bound alone does not imply the outer bound. The selected-site
checker inspects both actual constants, guards and ordering; exact-length
regressions confirm equality is accepted and one byte less is rejected for
each serializer. Earlier long-tag fixtures exhibit each distinct failure.
