# E7C/0.1 compatibility boundaries

## Baseline rule

The compatibility reference is v0.12.1-experimental, profile `RGP/0.1`,
revision `RGP2`, at merge commit `4867f369…` and canonical blob `a84da2c…`.
Successor material is never substituted for this source.

## Boundaries by source line

| Boundary | Required preservation | Compatibility evidence still required |
|---|---|---|
| v0.12.1 → E7C | Source types, admission, outcomes, identity, source/view, dependence, operation order and failure distinctions | Adapter-specific preservation/reflection proofs or explicit quotient/loss |
| RGP/0.1 → RGP/0.2 | Hosting/generation/encoding/decoding/projection/inheritance/composition and independent coordinates | Complete semantic differential; changed laws/outcomes; positive and negative fixtures |
| RGP/0.2 → WPC/0.1 | WPC is a distinct successor bridge, not implied by recursion | Introduction differential and non-WPC counterexample |
| WPC/0.1 → WPC/0.2 | Legacy WC meanings remain pinned; reciprocal constitution is an extension | Extension differential, migration effects and non-equivalent cases |
| v0.13 → v0.14 | Inherited EEC-Q/SF/CFS/RGP/WPC meanings remain unchanged | Byte/semantic preservation differentials GPR-015–018 |
| REC → E7C | Support/refutation independence, provenance groups, editions, guards, status/policy split and replay | Translation fidelity; no truth/authority upgrade |
| MSC → E7C | Scope order, comparison spans, link/global closure, missingness policy and fibres | Derived-library conservativity and bounded completeness |
| E7C → products | Product-native semantics, identity, data and APIs remain authoritative | Two-consumer reuse and independent reproduction before shared dependency |

## Product snapshots at cutoff

- E7Q `19dd348…`: Q-A1/Q-A2 bounded candidate-family/history contracts are
  differential fixtures; quantum semantics remain product-native.
- E2CI `b596f0e…`: EvidenceState remains non-cancelling and is not silently CFS;
  provisional family/generation work is fixture evidence only.
- E7DB `8f9a366…`: storage may preserve opaque native objects but cannot infer
  semantics, independence, authority or reconstruction strength.
- E7Q-ENC `3106002…`: cryptographic guarantees remain external to E7G-T;
  structural envelopes cannot replace AEAD, key management or authorisation.
- E7-Ecosystem `e868fa2…`: governance snapshot, not mathematical authority.

## Migration result

WP0 changes no identifiers, schemas, fixtures, APIs or product pins. Later
adapters must be versioned, reject unsupported mandatory capabilities, and
state whether they are faithful embeddings, faithful interpretations with a
named quotient/loss, partial translations or unsupported.
