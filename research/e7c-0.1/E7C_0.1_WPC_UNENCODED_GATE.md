# WPC/0.2 unencoded constitution (review candidate)

Baseline: main `bbf15ca03743259f52d85b1afcbc9dd9860c7fbe`
(PR #114 merge). Source: v0.13/RWP1 X.19 W.3/W.4 and WPC/0.2
package profile WP6, text-identical X.19 in the v0.14/REC1 draft.
Source model: pinned `allocation-example/0.1`. Published v0.12.1/RGP2
remains canonical; WPC/0.2 is a proposed successor and WPC/0.1 WC0–WC4
retains its separate meaning.

The earlier finite `wpc_allocation_b1.constitute` takes an assembly whose
every portion carries a representation, constitutes its current local
values, and then checks that each representation decodes to the same whole.
That is a **strict reconstruction/closure case**, not the general claim that
semantic constitution requires encoding. The WPC/0.2 profile explicitly
permits coherent constitution without any SR4 portion.

The separate `wpc_unencoded_constitution_b1` admits a typed finite
`SemanticPresentation` of member occurrences, actual local integer values,
edition, epoch and events, **with no representation field**. It checks exact
occurrence coverage and the selected allocation budget, yielding a typed
`unique`, `incompatible` or `resource_limit` outcome. The result uses its own
`SemanticWhole` sort with the draft kernel edition; the v0.13 strict
representation function cannot silently encode a v0.14 result. Exhaustion reports
visited progress with no partial whole. `source_pin` validates both draft
kernel digests, identical X.19 text and the finite reference model digest;
v0.13 and v0.14 results retain distinct kernel identities.

The conventional baseline constructs the first-party model's `Whole`
directly from local values, without calling its `encode`, `alpha`, `decode`
or `beta`. Tests show a valid `(1,1,0)` whole under both editions, an
incompatible `(1,1,1)` presentation, zero/prefix budget stops, invalid or
misordered coverage, tampered edition pin and a type rejection when the
unencoded presentation is passed to strict reconstruction. An unencoded
success therefore makes **no SR0–SR4 claim**. It cannot be used as a
WPC/0.1 all-portions SR4 witness or as a WPC/0.2 `beta` result.

**Covered with an open link, not complete.** This is a tiny, closed allocation
interpretation, not arbitrary WPC constitution. The model does not provide
the general presentation (A), extraction \(\epsilon\), ambiguity,
undetermined/unavailable outcomes, relational dependencies, relative
reconstruction, independent source semantics proof, Lean refinement,
WPC-Evolution commitment or WPC-Distributed behavior. No version coverage,
canonical promotion or product migration follows.

Next WPC gate: connect this unencoded `A → Whole` judgment and the existing
encoded `Z → A → Whole` strict path with distinct typed rules, prove that
constitution alone implies no retention tier, and add explicit failure and
normalisation outcomes before any WPC/0.1→/0.2 migration claim.
