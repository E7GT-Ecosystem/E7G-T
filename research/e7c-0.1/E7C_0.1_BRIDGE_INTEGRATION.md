## Constructive transport theorem

`E7CEECQEmitterTransport.lean` supplies a finite emitter with separate stop,
charge, append, row-event and observation operations. `LocalContract` pins
each primitive pointwise to the selected typed operation. It has no
completed `Trace`, accepted checker result, expected final partition or
source/IR equality premise.

The emitter executes the declared finite control, generates its packets and
constructs a checker certificate. The theorems derive stream acceptance,
wire-terminal transport, independently instantiated source/IR agreement and
bounded IR acceptance under the two separate byte bounds. All typed machine
states, policies and finite budgets are quantified. A failed second append
charges its step, emits no append and sets `secondStarted`.

This is a generative completeness theorem for the declared emitter machine
under local primitive contracts. It does not identify arbitrary CPython
execution with that machine. Mathematical control correspondence, raw
parser/codec correspondence, stable host primitives and normal completion
remain explicit native trust/open boundaries. Changing their status requires
an actual source-to-operation derivation, not this theorem alone.

## Native byte-call binding

`e7c_ir_execution_capture.py` instruments the selected independent IR
executor in an isolated verification process. It retains the immutable
objects returned by the outer serializer and by the nested serializer, and
checks that each actual parse call receives that exact object exactly once.
The observation exporter uses these captured parser inputs; it no longer
obtains its evidence by post-execution reserialization.

The observer records the running emitters' own stream and result. It never
consults an expected partition or semantic transition checker. Missing,
repeated or rebound parse operations fail binding. Native exceptions produce
no successful capture; bindings are restored on every exit. Overlapping
instrumented captures are refused. Arbitrary concurrent external threads,
binding mutation, parser semantics, callback completeness and normal native
completion are outside this isolated-host contract.

The Lean byte-array checker still checks retained lengths rather than parsing
IR contents. Native operation identity is a trusted local premise; neither
object identity nor a digest proves universal execution provenance.
