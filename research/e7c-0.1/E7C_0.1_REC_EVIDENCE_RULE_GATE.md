# E7C REC evidence-only rule candidate

Status: `review_candidate; selected_source_admitted_subset; open_proof_link`.

Source edition `0.14-experimental-draft / REC/0.1-proposed / REC-B1/0.1`;
candidate `E7C-REC-EVIDENCE-B1/0.1-provisional`. For a **source-admitted**
one-claim envelope with no inference rules and policy `report` or
`rely_if_supported_only`, `rec_evidence_ir_b1.py` encodes a query and sorted
typed evidence rows. A row retains identity, polarity, provenance and both
time boundaries. Evaluation visits each row once in sorted identity order,
classifies stale evidence at the declared instant, accumulates independent
support/refutation bits and provenance groups, then emits one of four statuses
and an independently selected policy action. A visit limit yields a typed
`resource_limit` with exact prefix progress, no completed status or action.

Under complete visits, the denotation is the pair of existence predicates
over current scoped evidence: `(exists support, exists refutation)`.
The four possible pairs denote `neither`, `supported`, `refuted`, and `both`
without collapsing conflict or absence into Boolean truth. The source
admission premise checks the rest of the envelope, including modality,
scope, source IDs and timestamp validity. The selected IR's own admission
rejects mismatched editions, multi-claim and rule inputs, invalid policy,
duplicate evidence IDs, scope expansion and malformed time intervals. It
must not be treated as independent admission for the larger source schema.

Differential tests check eight status/policy combinations, stale evidence,
source versus IR admitted/stale ordering and provenance, and zero/one visit
resource prefixes. The separate source checker replays the source witness.
Negative cases reject rule closure and scope expansion; no confidence weight
or EEC signed coefficient enters this rule. These finite tests are **not** an
all-input refinement theorem. The source model has no matching visit-limit
operation, so only successful complete traversals have a source comparison.

Open links: formal Lean typing and preservation, all-input admitted-subset
source-to-IR proof, source checker versus independent IR witness replay,
multiple claims and fixpoint rules, modality bridges, general timestamps,
resource effects across the full REC rule family, source truth and reliance
authority. This is covered with an open link, not complete; v0.14 is a draft.
