# E7C/0.1 terminology and anti-collapse matrix

| Terms | Working distinction | Forbidden collapse |
|---|---|---|
| Entity / description / configuration | Entity is the modelled referent; description represents it; configuration is an admitted arrangement under pinned context/time | A record is not automatically its referent; descriptions are not interchangeable configurations |
| Configuration / formal state / family | Configuration is one admitted basis object; formal state is a profile-selected combination; family is a dependence-preserving set or description of alternatives | Membership is not a coefficient; a family is not an EEC-Q sum |
| View / projection / encoding / materialisation | View is inquiry-relative access retaining source reference; projection is a typed map, often lossy; encoding is governed representation with retention strength; materialisation realises a semantic whole under a contract | View is not source; digest/locator is not SR4; materialisation is not semantic whole |
| Whole / portion / compatible multi-scope family | Whole is constituted under a contract; portion is a participating occurrence/representation; compatible family satisfies declared inter-scope maps | Concatenation is not constitution; local agreement is not global closure |
| Exact identity / definitional equality / denotational equality | Exact identity binds canonical object+edition; definitional equality is decidable conversion; denotational equality is model-relative | Denotational equality cannot leak into type conversion |
| Isomorphism / observational equivalence / phase equivalence | Isomorphism is typed invertibility; observational equivalence depends on observations; phase equivalence depends on criterion/inquiry | None implies exact identity; phase equivalence is not general substitutability |
| Domain failure / unsupported / undetermined / resource limit | Domain failure rejects an admitted operation at its domain; unsupported names absent capability; undetermined retains unresolved obligation; resource limit records bounded interruption | None becomes successful empty output |
| Empty family / zero state / empty reconstruction fibre | No admitted alternatives; additive identity of a state algebra; exhaustive view fibre with no sources | These three values are pairwise distinct |
| Evidence polarity / information status / source truth / decision authority | Polarity supports/refutes; status records available bits; truth is external/domain claim; authority licences action | `supported` is not true or authorised; `both` must not collapse |
| Rank / scope order / time / access / authority | Construction nesting; locus order; temporal frame; visibility capability; permission/power | Ordering or magnitude in one coordinate implies nothing in another |
| Hosting / generation / inheritance / composition | Addressable containment; successor construction; declared preservation; bounded joining | No relation implies another |
| Reconstruction compatibility / representation agreement | Membership in the same declared source fibre; agreement of materialisations under a contract | Neither is identity or unique reconstruction |
| Witness / proof / empirical result | Witness supports replay under pins; proof establishes a formal proposition in a trusted base; empirical result measures a frozen procedure | Passing replay/test is not source truth, theorem proof or product value |
| Canonical / candidate / proposal / implemented | Current authoritative experimental source; possible successor; review object; executable subset | Higher version, merged file or runnable code does not confer canonical status |

Notation is deliberately not fixed by this matrix. Any later WP1 notation must
preserve these separations and remain subject to review.
