# Raw Joint JSON admission and typed normal-return composition

This draft continues the accepted bounded sort/constructor model in #145 at
exact parent `407f35c1fde3dd3a87de9fbd66585900ab720783`. It adds an untyped
JSON-value model for the pinned EEC-Q Joint document boundary and a conditional
composition theorem with the typed normal-return path.

## Admission model

`E7CJointRawJsonAdmission.lean` treats `RawJson` objects as JSON values
already produced by a parser. It defines exact-key checks and decoders for the
document, resource policy, interpretation, two-coordinate row, graph and
coefficient shapes.

| Input field | Model check |
|---|---|
| Document | Exactly the nine pinned keys; edition, blob IDs, predicate and type labels match the pinned constants |
| Resource policy | Exactly `step_bound` and `ledger_bound`; exact JSON integers (booleans excluded), both nonnegative |
| Interpretation | Exactly `capability` and `obligation`; capability is a JSON boolean and obligation is `resolved` or `unresolved` |
| Rows | JSON array with at most 64 entries; the source's 64-row cap rejects as invalid input |
| Row | Exactly `atoms` and `coefficient`; atoms is a two-element array preserving coordinate order |
| Graph | Exactly `edges` and `tag`; edges are registered, unique and in canonical order; tag is null or a string, preserving null versus empty string |
| Fraction pair | Exactly `numerator` and `denominator`; both exact integer tokens, denominator positive and numerator nonzero; value decodes to exact `Rat` |

The mathematical decoder maps a valid integer pair `(n,d)` to `n/d`.
The helper's later `rows(value) == source['rows']` guard compares the emitted
reduced Fraction numerator/denominator with the original raw pair. Thus
unreduced pairs may decode to a value but cannot pass the canonical normal
return guard. Duplicate, cancelled, reordered or otherwise noncanonical
support is likewise rejected by that raw rows equality after Joint
normalisation.

## Outcome separation

The modeled boundary distinguishes four outcomes: accepted document,
invalid input, uncaught helper exception, and resource interruption. JSON
syntax rejection and caught admission failures classify as invalid input. The
pinned 64-row cap also rejects as invalid input; it is not the evaluator's
`resource_limit` outcome. Uncaught exceptions and runtime resource
interruption remain separate outcomes. This Lean layer does not derive which
exceptions or resource failures the running CPython process produces.

## Composition theorem

`RawTypedNormalReturnTrace` composes:

1. a successful result of the raw structural decoder;
2. the existing typed `ModeledNormalExecution` over the decoded ordered
   `WireRow` list;
3. an operation-level observation that the raw `rows(value)` serializer
   refines to the modeled raw encoding of the returned typed rows; and
4. the successful raw list/dictionary equality guard.

The theorem derives the typed result as the decoded input rows mapped to
`Row`. The successful raw serializer observation and raw equality guard remain
explicit fields of the trace; the theorem does not independently prove a
CPython serializer/decoder round trip. The proof does not assume a completed
constructed result as its premise.

The object tree begins after JSON parsing. This increment does not establish
that CPython's parser, `require_canonical_json`, Python helper calls or
serialization satisfy the model's operation observations. It is an
operation-level conditional model, not full CPython implementation evidence.
