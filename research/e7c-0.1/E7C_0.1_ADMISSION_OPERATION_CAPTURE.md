Baseline: main `89d4c0d094f79e0c3f583e1f2513df2ef184bd27`, after #169.

## Captured execution

`e7c_joint_admission_operation_capture.py` runs the original `admit` body and
uses `sys.setprofile` without replacing helper, constructor, or imported
primitive bindings. It records call and return frame events for `admit`,
`_graph`, `_row`, `rows`, `Config.__init__`/`__post_init__`,
`Fraction.__new__`, `joint`, and `Joint.__init__`/`__post_init__`. Exact native
values are frozen at these frame boundaries. It imposes finite row, event and
receipt-size limits, requires a single-threaded uninstrumented process, and
returns a packet only after the selected normal path completes.

Source identity is rechecked with the existing complete helper AST pin. The
capture does not alter dispatch or compute a parallel expected result. The
focused test checks a negative coefficient, distinct `None` and empty tags,
and the real default `Fraction(0)` used by dictionary lookup. A Boolean in an
integer field is separately shown to raise the adapter's admission exception;
no successful packet is returned for that execution.

The call profiler and its event callback are trusted observers. A passing
receipt is finite execution evidence only. It is not a verified Python
interpreter, a proof that the profiler cannot miss or perturb an event, or an
all-input translation. In particular, the `joint` frame boundary does not
certify its internal dictionary or `sorted` operations. The Lean
`first_stage_normal_return_composition` remains conditional on the statement
traces and the separately listed operation contracts; this capture supplies
no theorem premise automatically.
