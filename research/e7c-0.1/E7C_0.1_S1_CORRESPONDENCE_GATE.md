## Finite mathematical fragment

Let `G` be admitted fixed-label FG3 graphs with exact edges and optional
tags. A state `S` is a finite-support function `G → ℚ`; a binary joint `W`
is a finite-support function `(G × G) → ℚ`. Coefficients, including negative
ones, are formal signed values and are not probabilities or evidence weights.

- `independent(S,T)(p,q) = S(p)·T(q)` is an **explicit** factorisation request.
  A joint given as input is authoritative; it is never reconstructed by
  multiplying its marginals.
- `marginalᵢ(W)(p) = Σ_{q: coordinateᵢ(q)=p} W(q)`.
- `strict_union(W)` is defined iff every pair in `supp(W)` has equal tags.
  On success, each pair contributes its coefficient **once** to the graph
  whose edges are the union of its two edge sets and whose tag is shared.
  Equal output graphs collect by exact rational addition. Otherwise the
  entire result is `domain_error`, with no state or compatible-only prefix.
  The zero joint has empty support and maps to the zero state.

These are selected FG3 equations from canonical §§X.3–X.5. They do not
generalise to unknown interfaces, arbitrary gluing, non-finite states or
other profile modules. Admission validates every raw input row before
collection; the strict predicate then ranges over **canonical support**.

## Versioned operational correspondence

`e7c_s1_state_joint_static.py` admits the exact `State`/ordered `Joint` types
and the strict terminal `Outcome[State,extension]`. The runtime first checks
the term and all finite inputs. It charges one step at each term entry and
one visit immediately before processing each supported pair. Operands run
left-to-right; completed operation ledger entries are appended in postorder.
The first incompatible supported pair yields whole domain failure and one
ordered failure entry. If a resource bound is hit before examining that pair,
`resource_exhausted` takes precedence, retaining prior progress and completed
ledger entries but never a partial value. The replay checker independently
recomputes these operations while sharing only static admission and the
finite input codec.

For sufficiently large resource bounds, the intended observable relation is
`decode(S1.evaluate(t)) = FG3.evaluate(translate(t))` on the explicitly
admitted finite fragment, comparing canonical support and signed coefficients
on success and whole domain failure on strict rejection. Resource-limited
progress and ledger are S1-specific additional observations. The source
model has no equivalent bounded-resource trace.

`test_s1_source_correspondence.py` imports the actual pinned source example,
not the S1 adapter. It checks all 16 fixed-label graph configurations in
each coordinate with both coefficient signs (512 singleton cases), all
ordered two-row pairs over four selected graph configurations with both
second-row signs (512 cases), and the zero joint: **1,025 differential
cases**. Each S1 witness is replayed. Checks include the exact source
result/failure, static effect atoms, visited-prefix length and terminal
ledger; source file hashes are asserted before testing.
