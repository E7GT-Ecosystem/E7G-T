## What changes

#158 executes checked translations of `_graph`, `_row` and `rows` using a
selected Lean evaluator. This increment defines a separate normal-execution
relation and proves that operation derivations agree with that evaluator.
The relation is not defined by an `eval = some output` equation.

The primitive relations describe lexical lookup, attribute reads, conversion
to raw data, one/two-target binding and `list` copying. `PrimitiveAdequacy`
states the meaning of each such operation relative to the selected value
representation. It contains no complete serializer result, row-encoder
equality, final-guard success or finished `RowsStatementTrace` assumption.

Dictionary and array literals evaluate each child and preserve the declared
literal order. `Visits` pairs complete input/output lists positionally; its
length theorem excludes omitted/extra visits. Comprehensions use those visits
with explicit scope binding. Unknown helper calls have no normal derivation.

The helper call hierarchy is acyclic:

| Helper | Call relation used | Soundness supplied by |
|---|---|---|
| `_graph` | `list` on sequence values | primitive list-copy contract |
| `_row` | `_graph` operation derivations | `graph_normal_sound` |
| `rows` | `_row` operation derivations | `row_normal_sound` |

The generic soundness theorem has a call-refinement premise. For the final
serializer theorem, the two helper-call refinements are derived through this
hierarchy; they are not supplied as whole helper-output equations.

For every finite modeled binary row list, `modeled_rows_normal` constructs a
derivation from the mathematical primitives. This ensures the relation is not
vacuous. `operation_normal_exact_rows` derives the ordered exact encoding from
an operation derivation and the local contracts. It preserves correlated
coordinates, edge lists, null/string tags and the returned rational pair.
The trace/domain theorems derive the existing serializer trace, unique keys
and 32-fuel safety. `changed_output_has_no_normal_derivation` rejects any
different raw result under those same contracts.

The separate guard module composes this result with #157/#158's conditional
admission, Joint and final comparison results. It inherits their
`Classical.choice` use; the pure operation module retains the strict audit.

## Exact open host boundary

`modeledOperations` and `nativeAttributes` are mathematical definitions.
They do not import, execute or verify CPython. `RowsNormal` describes a
selected operation derivation, not a record observed from a running interpreter.

| Boundary | Evidence in this increment | Still needed |
|---|---|---|
| Selected expression relation to #158 evaluator | all-input Lean soundness | no remaining internal soundness premise beyond local primitive/call contracts |
| Complete ordered visits and scope binding | relational rules and constructive all-list derivations | CPython iterator/unpack/lexical execution supplies those visits |
| Native graph/Fraction/Joint representation | unchanged typed carrier and explicit attribute contracts | actual object representation and read adequacy |
| Helper calls and exact native binary guard | acyclic modeled call relations and typed input boundary | live bindings, call dispatch and guard adequacy |
| Dictionary/list construction and raw denotation | selected relation and conversion contracts | native construction/denotation correspondence |
| Final Python equality | inherited independent contract | actual dict/array/scalar comparison adequacy |
| Admission and Joint normalization | inherited conditional results | decoding, Fraction, Config, aggregation, sort and constructor links |
| Exceptions, nontermination, interruptions | excluded from normal relation; finite interruption regression | separate host outcome semantics and proofs |

The relation's 16 index counts **expression nesting**, not consumed Python
steps. It does not limit list length or establish wall-time, bit-growth or
host-resource behavior. Actual admission still has its existing 64-row bound.
The serializer uses the returned `Rat` pair; this does not identify original
raw `2/4` and `1/2` in admission or the final guard.

No theorem here asserts that every actual normal CPython return supplies
`RowsNormal`. That is the next host adequacy obligation. Complete matching
helper frame entries in finite tests are not a producer or proof of this
operation relation, and do not observe every opcode or attribute read.
