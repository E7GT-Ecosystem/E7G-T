The adapter composes the pinned source evaluator and its separately coded
checker through a versioned, closed envelope boundary. Admission checks the
selected schema fields and source semantic guards, then freezes canonical
envelope bytes. Execution obtains a source witness and independently replays
that witness against the same bytes before a `CheckedTrace` can be returned.
External witnesses pass through the same checker. Edition or envelope changes
invalidate replay; changing the caller's input object after admission does
not change the admitted envelope.

The checked result keeps the claim statuses, query status, separately chosen
decision action, provenance dependence groups, two source/checker hashes
and a three-event bounded effect record. No numerical evidence weight or
EEC coefficient can enter the closed envelope. Tests cover all four
non-collapsing information statuses, report versus reliance policies,
shared provenance, scope expansion, edition changes, input mutation, and
a re-signed forged action rejected by the separate checker. The entire
first-party source test suite runs alongside these integration tests.

This **reuses the first-party evaluator and checker**. It is a typed
integration target, not an independently derived REC semantics, general
proof, autonomous fact checker, legal truth assessment, empirical AI
improvement, or production reliance authority. `CheckedTrace` means only
that the selected deterministic model's replay matched the declared
envelope; it does not verify proposition truth or expert domain rules.
The next REC gate is an E7C grammar/IR, operational and denotational rule,
then a replaying E7C witness checker with independent reproduction.
Published v0.12.1/RGP2 remains canonical; the v0.14 proposal is not promoted.
