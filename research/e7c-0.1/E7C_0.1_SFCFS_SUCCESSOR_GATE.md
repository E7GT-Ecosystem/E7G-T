# SF/CFS inherited editions: finite points replay (review candidate)

Baseline: main `bd1d4fd48b7ca9f98802d8f9849b96297165a059`
(PR #113 merge). Published v0.12.1/RGP2 is canonical; v0.13/RWP1 and
v0.14/REC1 remain drafts. The selected X.16 SF/0.1 and X.17 CFS/0.1 text
is byte-identical in all three pinned kernels. This is a narrow reason to
replay an earlier **selected** finite model, not a proof of full inherited
semantics at either successor edition.

`sfcfs_successor_binding_b1.py` validates all three kernel SHA-256 digests,
the unchanged SF and CFS sections, and exact SF/IC and CFS/CG3 model digests.
It binds the existing finite-points `Family` to an explicit kernel edition;
shared composition, point restriction and realisation preserve the binding.
Two families from different kernel editions cannot be silently composed.
The outer set of assignments remains distinct from signed coefficients in
each inner EEC-Q state.

Three test methods run the same exact rational finite points under both
draft editions and compare symbolic terms, pointwise states and realisation
with the pinned first-party CG3 evaluator. They test zero inner state versus
empty outer family, resource-limited realisation, forged source pin and
cross-edition composition. The existing `test_sfcfs_points_b1.py` keeps the
shared-parameter versus independent-product counterexample; the workflow
runs both suites and the first-party source checks.

This is **bounded differential coverage with an open link**, not completed
SF or CFS fidelity. No new general SF solver, arbitrary intervals/radicals,
symbolic constraints, quotient equality, ordered realisation proof, general
CFS nesting theorem or Lean source-to-adapter refinement is supplied. It
does not turn finite SF membership into EEC coefficients or support a
different evidence algebra. Those proof and execution obligations remain
separate for both v0.13 and v0.14. No canonical or consumer migration.

Reproduction:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=research/e7c-0.1/adapters \
  python3 -m unittest discover -s research/e7c-0.1/adapters -p 'test_sfcfs_*.py' -v
```
