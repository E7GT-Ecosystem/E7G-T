## Model change

`E7CJointRawJsonAdmission.lean` now defines:
- recursive raw-value well-formedness, requiring unique object keys at every
  depth;
- recursive normalization that sorts object fields by their string key while
  preserving array element order and scalar constructors and values; and
- `rawJsonEquivalent`, which requires both values to be well formed and their
  recursive normalized trees to be structurally equal.

This captures Python's JSON-shaped equality boundary for decoded objects:
dictionary insertion order is ignored recursively, list/array order remains
significant, and booleans, integers, strings, null, and exact rational pair
members remain distinct. Duplicate-key object lists are outside the equality
domain; accepted shape decoding already rejects duplicate keys.
