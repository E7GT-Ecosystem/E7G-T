## Model change

`E7CJointRawJsonAdmission.lean` now defines:
- recursive raw-value well-formedness, requiring unique object keys at every
  depth;
- recursive normalization with fuel 32 that sorts object fields by their string
  key while preserving array element order and scalar constructors and values;
  the fuel bound is intended for the fixed-depth admitted document/row shapes
  in the pinned decoder, not arbitrary-depth JSON; and
- `rawJsonEquivalent`, which requires both values to be well formed and their
  recursive normalized trees to be structurally equal.

Within the admitted document and serialized-row shapes, this captures the
Python JSON equality boundary: dictionary insertion order is ignored
recursively, list/array order remains significant, and booleans, integers,
strings, null, and exact rational pair members remain distinct. The pinned
shape decoder admits only a shallow fixed schema (at most a handful of nested
object/array levels), well within the 32-level normalizer fuel. The Lean
increment does not claim completeness for arbitrary RawJson deeper than the
fuel bound. Duplicate-key object lists are outside the admitted equality
domain; the exact-key decoder rejects duplicate keys at each object it accepts.

## Re-derived bounded consequence

`RawTypedNormalReturnTrace` now states serializer refinement and the final
raw equality guard with `rawJsonEquivalent`. Symmetry and transitivity of the
relation derive:

`rawJsonEquivalent document.rawRows (encodeRawRows (result.map fromRow))`

The encoded form preserves row order, the two Joint coordinates, graph edge
order, null versus empty-string tags, and each Fraction's exact numerator and
denominator. This is a conditional model theorem: it composes typed normal
execution with explicit serializer-refinement and equality observations. It
does not derive those observations from running CPython.

## Focused evidence

The Lean examples cover:
- recursively reordered object keys compare equal;
- reordered arrays remain distinct;
- null and empty string remain distinct;
- 2/4 and 1/2 raw Fraction pairs remain distinct; and
- duplicate-key objects are excluded from the well-formed equality relation.

Focused pinned Python checks cover a positive recursive object-key permutation
and adversarial input changes: unreduced 2/4, reordered rows, swapped ordered
coordinates, reordered edges, and null versus empty-string tags. The prior
suite also checks duplicate and cancelled rows and booleans used as integers.
