## Declared scope and disposition

`adapters/eec_q_fg3_fibre_b1.py` is a **provisional partial translation** of
source-retaining phase viewing and candidate-relative phase reconstruction on
the complete eight-graph untagged FG3 basis. `project_view` records its pinned
view edition, exact retained source, edge-count observation, hidden exact edge
identity, preserved information and `exact_retained_source_only` return policy.
`source_return` accepts this view type and returns its retained source. It
rejects a `PhaseState` produced by lossy `identify_phase`.

`reconstruct_fibre(phase, carrier, budget)` accepts a distinct `PhaseState`
and a caller-declared finite, canonical, edition-named list of admitted graph
states. It compares the image of **every** listed candidate and returns
exactly those with the requested phase state. This is a complete fibre *only
relative to that specific candidate list*. It is not the full inverse image
among all finite rational graph states, whose coefficients are unbounded.
An empty carrier may therefore yield successful empty **relative** fibre;
it proves nothing about global impossibility. A singleton relative result
does not prove globally unique source reconstruction. The result binds the
complete carrier and target, so a success cannot omit a matching listed
candidate. An insufficient comparison budget returns `resource_limit` with
no partial successful fibre. Carrier admission itself occurs before that
comparison budget; this is not a total wall-clock or memory bound.

The phase quotient and fibre here are candidate interpretations of the
canonical mathematical semantics; FG3 has no executable quotient or
reconstruction API. The direct source comparison checks that source-retaining
view return preserves the exact FG3 state. Other cases are algebraic fixtures
of the canonical projection definition. This module does not claim FG3
source-to-target differential conformance for a nonexistent source API.

## Loss, exclusions and gate

The declared quotient equates untagged graphs with equal edge counts; it
discards exact graph identity and can cancel opposite coefficients. The finite
fibre restores **candidate alternatives**, not lost source evidence. No
selection, ranking, probability, source truth or exact source return follows
from that quotient. Tagged configurations and undeclared phase criteria are
rejected. This in-process value API carries no persistent witness, integrity
proof, external input authentication, general resource accounting or stable
schema. It is not a new constructor in the accepted E7C-B1 core and does not
change its existing static rejection rule.

Five test methods cover retained source vs lossy phase, ambiguous and
cancellation preimages, resource exhaustion, relative-scope limitation,
forged incomplete success and invalid carrier admission. The exact-head gate
must review both the source-return and finite-carrier semantics and explicitly
preserve the relative-completeness boundary. WP5 still needs general
projection/reconstruction laws and proof, pair/wire-choice gluing, mixed-rank
quotation and later profile adapters. No canonical/profile change or
ID/data/API/consumer migration is proposed.
