construction rank 0–1024, explicitly separate regime, temporal scope, access
scope and composition scope. It matches the companion's canonical record and
identity digest for admitted examples. A local `Hosted` relation remains
separate from `Generation`: neither relation establishes the other. Generation
uses a reviewed shallow carrier update, named inherited invariants and an
incremented rank. Arbitrary source `transform` callbacks are outside this
finite fragment.

Role-gated projection keeps source identity, preserved fields and declared
loss. Exact reconstruction from a lossy projection is rejected unless a
matching full SR4 payload is supplied; full-field projection can be checked
against the source digest. SR4 decoding checks payload digest, canonical
bytes, source identity, source edition, codec edition and retention tier.
The correction requires strict full-record `Layer`/`Placement` admission and
an exact reconstruction check for the source sort before returning decoded
material; a recomputed digest alone cannot admit an ill-formed layer.
Finite composition preserves component identities and rejects repeated
occurrences without an independent occurrence identity. Four differential
test methods compare the pinned RGP companion on source records, identity,
generation edge, projection fields and loss, SR4 payload/decoding and
composition; negative tests cover admission, mismatch and tampering. The
first-party RGP validation also remains a separate gate.

finite companion does not export either operation, and this PR makes no
executable correspondence claim for them. Hosting here is only a typed local
identity relation: the canonical §R.2 interface position, quoted component
and host boundary contract remain unimplemented. The selected projection
has no temporal-locality index. Authorization, distributed placement and
actual external hosting are unproved. Authority has no inferred rank or scope relation. The core
calculus has not yet admitted these RGP terms, and general recursion,

profile, schema, product or API migration follows from this partial gate.
