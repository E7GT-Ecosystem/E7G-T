## Admitted fragment and source relation

`adapters/eec_q_fg3_phase_b1.py` supplies two separate bounded paths.

- `edge_view` mirrors FG3's graph-state `edge_view`: it retains the exact
  source `State` and displays edges and exact coefficient strings. Semantic
  tags can be hidden in the display but remain in the source. `EdgeView` is
  not a state argument and cannot trigger coefficient collection.
- `phase_view`, `identify_phase` and `phase_status` use the **complete eight
  untagged FG3 graphs** and the immutable criterion
  `FG3-UNTAGGED-EDGE-COUNT/0.1`. Phase view groups without replacing source
  terms. Explicit identification computes a new `PhaseState` with exact
  rational coefficients collected by edge count; it can cancel distinct
  graphs. The result has no implicit conversion back to graph `State`.
  Tagged states are rejected at this phase boundary instead of losing tags.

The source FG3 model directly implements edge views and a `phase_status` check.
The target compares their display/source and status booleans respectively.
FG3 has no phase quotient state API: `identify_phase` and `phase_view` are
candidate translations of the **canonical mathematical distinction**, tested
with algebraic fixtures but not source-to-source differential operations.
Quotienting erases exact graph identity; the declared quotient is equality of
edge counts on this untagged carrier. Reversing it requires the original
source/fibre, which the `PhaseState` does not contain. This loss does not
license exact reconstruction or a source-preserving `View` coercion.

## Descent gate and exclusions

`phase_status` checks all within-class pairs on the finite declared carrier.
It records separate domain-saturation and result-congruence booleans and a
counterexample pair for each failure. Adding `AB` to the same-edge-count
class is total but result-incongruent; requiring `AB` to be absent has an
unsaturated domain. The adapter does not offer phase-level execution for
either rule. The finite exhaustive check is not a theorem about arbitrary
signatures, criteria or unbounded phases.

No quotation, pair/wire-choice gluing, arbitrary predicates, phase witness
schema, resource limit, generic projection/reconstruction or rank extension is
implemented here. The graph-only target remains provisional and external to
the accepted E7C-B1 static/operational core. No canonical/profile meaning,
IDs, data, schema, API or consumer is migrated.
