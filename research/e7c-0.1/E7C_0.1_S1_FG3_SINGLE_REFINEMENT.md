# S1 single-support FG3 refinement candidate

Status: `bounded_first_party_candidate; selected_one_row_only`.

Base: main `b28005747d3ce1c5b634bad4e4439dc8e0d30154`.
Source: E7G-T v0.12.1/RGP2 §§X.2–X.5 and the pinned FG3/0.1 example.
Proof vehicle: Lean 4.34.0, provisional.

`proof-packages/lean-core/E7CS1FG3Single.lean` introduces a second Lean
definition of the FG3 strict-union result on **one admitted nonzero support
row**. It represents the fixed AB/AC/BC edge set as booleans, and a fixed
injective encoding of the admitted optional tags as `Option Nat`. A row is
typed by construction as a pair of FG3 graphs with one exact rational
coefficient. Inputs are assumed already admitted and canonicalised; neither
raw input validation nor arbitrary tag encoding is proved here.

The source-side definition returns the edge union with its shared tag and
unchanged coefficient, or whole domain failure for unequal tags. The
operational definition first charges two term entries, then one pair visit
before comparing tags. It records the matching success or failure entry;
resource exhaustion returns no value or new ledger entry. Lean proves:

| Property | Exact bound |
|---|---|
| Terminal correspondence | At least two term steps and one pair visit, for one admitted nonzero row |
| Resource precedence | A deficient step or visit bound stops before comparison and produces no partial state |
| Ledger and progress | Compatible and incompatible cases have the expected single terminal event and counters |
| Exact cancellation lemma | Two opposite rational coefficients collected at the same graph yield empty support |

This is a relation between independently stated **Lean source and
operational definitions**. It does not verify the Python evaluator, the
source example implementation or the JSON codec. The one-row theorem does
not cover zero support, multi-row traversal, collisions or cancellation in
the operational run, nested terms, arbitrary strings/graphs, input
admission, or the full static-effect relation. The cancellation lemma is
algebraic preparation only; it is not an operational theorem. The previous
1,025-case source comparison remains separate finite evidence.

Next: extend the relation to canonical multi-row support, collision
collection and cancellation, then prove that the Python/FG3 codecs preserve
the selected Lean observations or record a counterexample. E7C-T017 and
full calculus adequacy remain open. No canonical source, profile, product,
schema, data or API migration follows from this candidate.
