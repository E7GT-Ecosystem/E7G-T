## IR variable binding

`lower` now carries the source interpretation edition and precisely the
atomic finite carriers used by the variable type. The parser validates a
binding against its parsed type and these edition-bound carriers before
`execute` can return any terminal outcome. This calls the same WP3-I
value/terminal admission relation already used to validate source packages;
it does not import source evaluator control flow. Outcome success values
must lie in their carrier and have an unbound optional witness. A malformed
terminal or out-of-carrier value is rejected even if an adversary rehashes
the IR ID. Missing, duplicated or noncanonical carrier material is rejected.

The carrier list and digest are not trusted external authority: replacing
both the carrier and value and recomputing every ID can yield a distinct
self-consistent document. Full source/IR correspondence and a replayable
witness still require the complete pinned source package and independent
verification. The original optional success-witness mismatch remains open.

## Quoted layer and SR4

One `reconstruct_layer` validates all top-level fields, exact placement
coordinates, source identity/edition and the admitted `Layer` constructor
shape. `unquote` and `decode_sr4` use it before returning the full source.
Tests replace individual fields while keeping all top-level keys, recompute
the payload and source digests, and require both entry points to reject the
ill-typed result. Exact round trips of the pinned RGP companion continue.
