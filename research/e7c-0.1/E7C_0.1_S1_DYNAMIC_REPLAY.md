## What runs

The S1 static checker first checks the program. Runtime admission checks every
finite graph row, including rows with zero coefficients that later cancel.
Only variables of the registered FG3 `State` and ordered `Joint` types run.
The executor computes exact rational independent products and indexed joint
marginals. Graph identity includes every admitted edge and tag; joint rows
retain the shared choice until an explicit marginal discards a coordinate.
Zero states and zero joints retain their carrier and arity.

An edition-pinned finite resource policy bounds term entries and supported
pair/row visits. Exhaustion returns one `resource_exhausted` terminal with no
partial result, while retaining the completed operation ledger and counters.
Successful output carries a canonical finite value, ordered operation ledger
and actual resource progress. The static resource effects are bounds on
operation kinds, not exact numeric cost guarantees.

`e7c_s1_replay_checker.py` has a separate product, marginal, collection and
resource control flow; it never imports the evaluator. Both share only S1
static typing and finite input admission/serialization. Replay verifies the
supplied inline inputs, version pins, typed result, exact rational output,
ordered ledger and progress. This is a bounded recomputation claim. It does
not authenticate who supplied the inputs or certify that the declared source
graph represents anything outside the finite model. The inline witness is a
research structure without a stable schema or cryptographic provenance.
