# S1 finite FG3 support traversal

Status: `bounded_first_party_candidate; pre_collection_only`.

Base: main `f42da01d8857395b8621f60c51319e5859644b95`.
Source: E7G-T v0.12.1/RGP2 §§X.2–X.5; FG3/0.1 executable example.
Proof vehicle: provisional Lean 4.34.0.

`proof-packages/lean-core/E7CS1FG3Rows.lean` extends the selected one-row
model to an ordered finite list of already admitted, nonzero support pairs.
It carries exact rational coefficients unchanged and joins the fixed
AB/AC/BC edges for compatible tags. It consumes one visit before each pair
check. The source-side `firstBad` definition independently computes the
first incompatible support index. `sufficient_visits_match_source` proves by
list induction that an exact visit budget equal to the support length
returns the same complete ordered images, or the same whole domain failure
and first offending index. A scan stopped by a resource bound has no partial
value. Term-entry step accounting and the terminal ledger shape are
represented separately by `runRows`.

The successful images are **pre-collection contributions**, not a canonical
EEC-Q state. If distinct pairs join to the same graph, their coefficients
still require exact rational addition and zero removal. This package does
not prove collision collection, cancellation, Python evaluator behavior,
input/edition admission, sorted canonical support, static-effect/ledger
correspondence for arbitrary nested terms, or E7C-T017. It does not
redefine FG3 strict union to preserve duplicate output graphs. The existing
finite source comparison covers those cases as tests, not proof.

The next proof gate is a constructive rational collision operation with a
clean axiom audit, followed by its relation to canonical S1/FG3 support
and the pinned Python codec. No canonical/profile/product/schema/data/API
migration occurs here.
