The finite adapter now carries a whole-layer quotation with an exact canonical
payload, source identity and separate quotation rank. `unquote` validates the
payload and rank before source return; it does not execute the layer.
`hosts` requires an actual quote, interface position, matching host interface
contract and admitted component signature. It records a separate host
relation without invoking generation, transformation or interior rules.
Construction rank of the host is not inferred from the quote's rank.

`contextual_view` pairs a retained whole-source quote in the model with an
explicit temporal locality and a role-gated, loss-accounted view. The model's
source access does not grant source access to the represented role. A lossy
local view cannot request exact reconstruction without the separate retained
payload gate. These relations are derived directly from the canonical text;
the pinned RGP-B1 source companion has no corresponding exported quotation,
hosting-boundary or temporal-view operations. Two anti-collapse tests check
boundaries, tampering, rank separation, role admission and loss. They do not
constitute an independent executable source differential.

Still open: general contextual expression semantics, arbitrary quoted sorts,
history transition and advice interfaces, independently proven SR4 law over
all admitted records, shared-parameter lineage, full interface and invariant
witnesses, authorization engine, distributed runtime and calculus-level terms.
The original simple `host` identity relation remains a bounded companion
fixture and must not be used as an RGP host-compatibility claim. No canonical,
profile, schema, data, API or product migration is proposed.
