## Translation and identity

The independent target `adapters/eec_q_fg3_quote_b1.py` admits an FG3 graph
`State` as the *entire* payload of one rank-one `Quote`. `pack` and `unpack`
preserve the exact canonical graph coefficients and tags. `QuoteState` is a
separate finite formal state over whole quotes, with exact rational outer
coefficients and cancellation by the full quoted-state identity. Quoting a
two-branch state produces one quote; collecting one quote per branch produces
two distinct entities. A quote of the graph zero has an identity and gives a
nonzero outer basis state under `unit_quote`; it is not the empty `QuoteState`.

`inside(rule, quote)` explicitly applies a registered FG3 graph rule to the
*whole* payload and returns either `success(new_quote)` or `domain_error` with
no partial quote. FG3's `inside` raises `DomainError` for the same strict
failure; the differential comparison relates that exception to the target
tag. The original quote remains unchanged. Direct `push(rule, QuoteState)` is
rejected at the target's typed admission boundary; source FG3 instead admits
mixed-rank states and raises `DomainError` when a graph rule encounters a box.
This direct-push path is **outside** the selected target translation, so no
source-to-target failure equivalence is claimed for it.

## Exclusions and review gate

The selected fragment contains `Graph`-only payload states, rank-one whole
state boxes, outer formal sums of those boxes and explicit `inside` with
registered graph rules. FG3 assemblies, arbitrary mixed-rank states, nested
boxes, recursive rank, rule quotations, graph/box union, generic `State[Σ]`,
stable representation encoding, resource limits and witness replay remain
unsupported. The accepted E7C-B1 core has no executable formal-state or quote
carrier; this is a provisional profile module, not an E7C core constructor.

Five differential/negative test methods check whole versus branchwise quotes,
zero quote versus outer zero, exact identity and cancellation, strict inside
failure, unchanged original payload and the explicit admission boundary.
Review at the exact head must verify these observations against both pinned
sources and the named exclusions. Passing cases do not prove general quotation
laws, E7C adequacy or independent implementation. No canonical, profile,
consumer, ID, schema or API migration is proposed.
