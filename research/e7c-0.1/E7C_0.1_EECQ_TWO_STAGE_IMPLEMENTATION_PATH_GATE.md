## Formal states and transitions

`E7CEECQTwoStageImplementationPath.lean` indexes an external `Trace` by
`Path.source` or `Path.ir`. Each starts from the exact admitted wire-row map,
the two declared policies and the step/ledger bounds of PR #105. A trace must
account for one of four mutually scoped transitions:

| Transition | Guard | Effect |
|---|---|---|
| terminal | cursor has terminal | return its complete typed observation |
| noFuel | cursor unfinished, zero remaining steps | resource limit, no visit or append |
| noLedger | cursor unfinished, a step remains, zero ledger space | charge one step, mark second attempt started if applicable, no append or cursor advance |
| visited | cursor unfinished, both resources available | charge, append exactly the next staged event, advance one cursor position |

`trace_refines_drive` proves by induction that **every** source- or
IR-labelled certificate obeying these constructors equals the staged Lean
evaluator observation. `source_or_ir_refines_run` specializes to the exact
wire-row initial state. `certified_ledger_is_wire_prefix` preserves all
correlated row values and ordering in the budgeted ledger;
`certified_exhaustion_has_no_partial_partition` yields resource-limit-only
termination and the exact step count. The failed second append law proves
step charge, unchanged ledger and `secondStarted=true` independently of the
finite cross-language fixture. The proof package has no `sorry` or new axiom.

## Actual Python source and IR paths

The source `evaluate` first invokes `evaluate_first`, then re-admits its
retained Joint; independent IR `execute` invokes `execute_first` and scans the
retained rows from the typed child result. Their selected first- and
second-stage charge and append sites now emit optional copied transition
records. The independent `check` function checks each emitted step against
the admitted wire plan, bound, exact event, and reported observation; both
paths emit equal records in the finite differential suite, including failed
append. This is actual per-step execution evidence and does not modify the
ordinary return value or replay witness.

PR #105's admission/encoding bridge, effects/predicate validation and
differential suite check their observable outcomes against a staged Python
specification at finite budgets. This package's Lean `Path` labels describe
the two actual *intended* execution routes, but Lean does not import Python
bytecode or prove that either function supplies a `Trace` for **every**
admitted document. In particular, the first-stage child calls, Python
instrumentation completeness, JSON package parsing, and the exact
correspondence of emitted records to Lean `Machine` remain external premises.
A certificate reconstructed solely from a final observation would not prove
that an implementation really visited each row; the new optional probes emit
at the charge and append sites themselves, which is stronger finite evidence
but still not an all-input implementation proof.

The next refinement gate is to prove the optional probes cover every actual
charge and append, relate first-stage child results and source Joint rebuild
to the admitted Lean initial state, and formally validate the transition
record/`Machine` correspondence. The finite tests reject an omitted charge,
ghost row, and a failed second-attempt append with `secondStarted=false`;
short-budget tests reject partial success. Until the remaining link is
established, the result is a conditional all-list theorem about certified
paths, not unconditional Python or IR implementation correctness.
