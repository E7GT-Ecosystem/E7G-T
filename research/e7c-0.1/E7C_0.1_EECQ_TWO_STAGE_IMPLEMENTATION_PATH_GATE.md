# Selected source/IR implementation-path relation (review candidate)

Baseline: main `047b59d2d1e04f67a8b6510c45edb9a393fac1b3`, the PR #105
provisional exact codec and model simulation. This package adds a separate
conditional transition theorem. Published experimental v0.12.1/RGP2,
profile and product interfaces remain unchanged.

## Formal states and transitions

`E7CEECQTwoStageImplementationPath.lean` indexes an external `Trace` by
`Path.source` or `Path.ir`. Each starts from the exact admitted wire-row map,
the two declared policies and the step/ledger bounds of PR #105. A trace must
account for one of four mutually scoped transitions:

| Transition | Guard | Effect |
|---|---|---|
| terminal | cursor has terminal | return its complete typed observation |
| noFuel | cursor unfinished, zero remaining steps | resource limit, no visit or append |
| noLedger | cursor unfinished, a step remains, zero ledger space | charge one step, mark second attempt started if applicable, no append or cursor advance |
| visited | cursor unfinished, both resources available | charge, append exactly the next staged event, advance one cursor position |

`trace_refines_drive` proves by induction that **every** source- or
IR-labelled certificate obeying these constructors equals the staged Lean
evaluator observation. `source_or_ir_refines_run` specializes to the exact
wire-row initial state. `certified_ledger_is_wire_prefix` preserves all
correlated row values and ordering in the budgeted ledger;
`certified_exhaustion_has_no_partial_partition` yields resource-limit-only
termination and the exact step count. The failed second append law proves
step charge, unchanged ledger and `secondStarted=true` independently of the
finite cross-language fixture. The proof package has no `sorry` or new axiom.

## Actual Python source and IR paths

The source `evaluate` first invokes `evaluate_first`, then re-admits its
retained Joint; independent IR `execute` invokes `execute_first` and scans the
retained rows from the typed child result. PR #105's admission/encoding
bridge, effects/predicate validation and differential suite check their
observable outcomes against a staged Python specification at finite budgets.
This package's Lean `Path` labels describe the two actual *intended* execution
routes, but Lean does not import Python bytecode or prove that either function
supplies a `Trace` for **every** admitted document. In particular, the
first-stage evaluator/IR-child call boundaries, Python loop execution, JSON
package parsing and the exact step-by-step correspondence of their internal
states are external premises. A certificate constructed solely from a final
observation would not prove that an implementation really visited each row.

The next refinement gate is to make both implementation paths emit an
independently checkable transition record at each actual charge, append and
terminal step, relate the first-stage child results and source Joint rebuild
to the admitted Lean initial state, and prove or explicitly assume every
recorded transition satisfies the formal constructors. Tests must reject an
omitted charge, ghost row, hidden second-stage exclusion, premature success,
and a failed second-attempt append with `secondStarted=false`. Until that
link is established, the result is a conditional all-list theorem about
certified paths, not unconditional Python or IR implementation correctness.
