# E7C/0.1 WP4-S initial metatheory

Status: `wp4_s_statements_and_proof_sketches_unreviewed`

Baseline: PR #39 merge `9f997801eba3ff526f7caa83b6a4a1980a713bcb`

Scope: the finite, binder-free E7C-B1 fragment fixed by the accepted WP2 and
WP3-S specifications, together with the disposable WP3-I implementation. This
document is a theorem inventory and proof-sketch package. It is not a
machine-checked development and does not establish conformance, soundness or
correctness of the implementation.

## 1. Proof vocabulary and shared hypotheses

Every obligation uses one of the roadmap statuses: `stated`, `proof_sketch`,
`proved_on_paper`, `mechanised`, `bounded_exhaustive_check`,
`counterexample_found`, or `withdrawn`. Tests may support a statement but never
upgrade it to `proved_on_paper` or `mechanised`.

Unless narrowed below, the B1 hypotheses are:

- `H1`: the environment, term, runtime values, interpretation and resource
  policy pass the exact WP2/WP3-I admission checks;
- `H2`: declaration and outcome-extension editions are pinned;
- `H3`: atomic carriers and interpretation tables are finite, canonical,
  duplicate-free and complete as required by the admission edition;
- `H4`: resource bounds are finite non-negative integers;
- `H5`: canonical JSON comparison and digest functions behave as their stated
  mathematical definitions, not as a host iteration-order oracle;
- `H6`: no host callback, network input or mutation occurs during checking or
  evaluation;
- `H7`: theorem conclusions concern only the B1 judgement and its declared
  model; they establish no source truth or domain authority.

## 2. Static obligations

### E7C-T001 — Formation and typechecking decidability

Status: `proof_sketch`.

Statement: for a finite JSON input, B1 admission and typechecking terminate and
return either one controlled diagnostic or one unique type/effect judgement.

Sketch: structural parsing descends through a finite acyclic JSON tree. Each
term rule recursively checks its single strict subterm and performs finite
dictionary lookups, finite-set unions and structural equality. Closed record
checks and recursive terminal-only checks also descend through finite trees.
No rule performs unbounded search or invokes user code. Induction on the sum of
the remaining type and term node counts gives termination. Rule heads are
disjoint by `tag`, and each side condition has a Boolean or unique diagnostic
result, giving uniqueness.

### E7C-T002 — Exchange for the reusable variable context

Status: `proof_sketch`.

Statement: permuting the serialized order of distinct bindings in `Gamma`
does not change an admitted B1 typing judgement.

Sketch: lookup is by exact variable identifier, not position. All other
declaration references are also nominal. Canonical output sorts effects and
does not serialize context insertion order into the judgement. Induction on
the unary term spine reduces the claim to the variable rule.

### E7C-T003 — Weakening by a fresh reusable binding

Status: `proof_sketch`.

Statement: if `Gamma |- t : A ! epsilon`, `y` is fresh, and `B` is an admitted
terminal-normal B1 type, then `Gamma,y:B |- t : A ! epsilon`.

Sketch: `t` contains no reference to `y`. Exact-name lookup of every existing
variable and declaration is unchanged. Induction on `t` preserves each rule
and its effect atom set. This is ordinary reusable weakening only; it does not
resolve ADR-001 for future linear, affine or consumable contexts.

### E7C-T004 — Substitution for the binder-free unary fragment

Status: `proof_sketch`.

Statement: if `Gamma,x:A |- t : B ! epsilon_t` and
`Gamma |- s : A ! epsilon_s`, then capture-free replacement of the unique leaf
occurrence of `x` yields
`Gamma |- t[s/x] : B ! (epsilon_t union epsilon_s)` after removing the empty
variable effect already counted at `x`. If `x` does not occur, the result is
ordinary weakening and `epsilon_s` is not added.

Sketch: B1 has no binders and every compound constructor has exactly one
subterm, so capture and duplication are absent. Induct on the term spine. The
variable case is the premise for `s`; each constructor case reapplies the same
rule because the substituted subterm has the required input type, and finite
effect union is associative and idempotent. Outcome-terminal admission implies
that an outcome-typed `x` cannot occur beneath a consuming constructor, so its
only occurrence case is the variable term itself.

### E7C-T005 — Structural conversion soundness

Status: `proof_sketch`.

Statement: B1 definitional equality implies equal interpretations in every
admitted B1 model.

Sketch: definitional equality is equality of parsed canonical type trees. Type
interpretation is defined by structural recursion on exactly those trees;
equal constructors and equal arguments therefore receive equal
interpretations. No converse is claimed.

## 3. Dynamic obligations

### E7C-T006 — Deterministic evaluation

Status: `proof_sketch`.

Statement: under `H1`–`H6`, a closed admitted term and initial resource state
have at most one terminal outcome, ordered ledger and progress record.

Sketch: induction on the term spine. Step charging has one arithmetic result.
The induction hypothesis fixes the child result and state. Each constructor
then follows one fixed program-order sequence. Tables are canonical functions,
guards are explicit, and finite candidates have one canonical order. Every
branch is selected by disjoint conditions, so the terminal tuple is unique.

### E7C-T007 — Type preservation for successful evaluation

Status: `proof_sketch`.

Statement: if `Gamma |- t : T ! epsilon` and admitted evaluation returns
`success(v,w)`, then `v` inhabits the success carrier of `T`; for a plain type,
that carrier is `T`, and for `Outcome[A,xi]` it is `A`.

Sketch: induction on evaluation. Variable values are recursively checked
against `Gamma`. Map and view table outputs are admitted against their target
carriers. Restriction selects only input-family elements. Reconstruction
selects only source-carrier elements. Classification partitions only admitted
fibre elements. Outcome variables return their already validated terminal
binding and never introduce a nested success.

### E7C-T008 — Effect preservation and ledger soundness

Status: `proof_sketch`.

Statement: for every terminal outcome, if `Gamma |- t : T ! epsilon` and
evaluation emits ordered ledger `lambda`, then
`atoms(lambda) subseteq epsilon`. Propagated failure retains the incurred child
prefix.

Sketch: induction on evaluation. The variable ledger is empty. The induction
hypothesis bounds the child prefix. Every constructor appends only atoms
introduced by its matching WP2 rule and does so after the child prefix. Guard,
domain and resource exits return the current prefix without deletion. Finite
set union bounds stable sequence concatenation after erasure.

### E7C-T009 — Declared progress

Status: `proof_sketch`.

Statement: every closed admitted B1 term under finite `beta` returns exactly one
declared terminal outcome and finite progress record; it does not enter an
undefined evaluator state.

Sketch: the term spine and each admitted carrier are finite. Every recursive
term entry consumes a step or returns `resource_limit`. Every candidate loop
either consumes one bounded candidate charge per check or returns
`resource_limit`. Ledger appends behave likewise. Complete admission excludes
missing rows and malformed values from the dynamic relation. Thus evaluation
terminates by the lexicographic measure of remaining term nodes, remaining
charges and remaining finite candidates.

### E7C-T010 — Reconstruction soundness and bounded completeness

Status: `proof_sketch`.

Statement: successful exact reconstruction returns precisely the canonical
finite fibre `{a in Carrier(A) | view_q(a)=v}`. If enumeration is interrupted,
the result is `resource_limit`, never successful partial data.

Sketch: closed admission makes the reconstruction list a canonical,
duplicate-free enumeration of the complete source carrier and makes the view
table total on that carrier. The loop considers every element once, adding it
iff canonical target equality holds. Success occurs only after the loop;
candidate exhaustion exits earlier with `resource_limit`.

### E7C-T011 — Witness replay soundness for the bounded claim

Status: `proof_sketch`.

Statement: if the independent checker returns `accepted`, the inline witness
replays to the claimed outcome, ledger, progress and derivation graph under the
pinned B1 editions. This conclusion is exactly
`bounded_derivation_replay`.

Sketch: acceptance follows only after canonical envelope identities, closed
derivation graph, rule pins, static judgement and runtime package are checked.
The checker then independently evaluates the term and compares the complete
outcome, ordered ledger, progress, bottom-up nodes and root identity. Digest
collision resistance is an explicit cryptographic assumption; source truth,
domain authority and evaluator correctness are outside the claim.

resource termination and exact finite reconstruction. Their status is
`bounded_exhaustive_check` over the named fixture space only. They are neither
proofs of E7C-T006–T010 nor substitutes for the proof-assistant spike.
