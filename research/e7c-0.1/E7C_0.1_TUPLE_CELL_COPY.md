## Proof and premises

`CopyRun` is an inductive relation for source reads, local reference results
and destination writes, with ascending indices. Its per-cell premise records
the result of `newRef`; it takes no completed output equality. Under the local
pointer-identity contract, Lean derives both the full pointer list and the
complete ordered event sequence for every finite source list. It also derives
existence in the selected relation, denotation agreement with #161's
`copyTuple`, and rejection of changed output cells. Repeated pointers retain
their multiplicity and positions. One stable pointer interpretation is used
for both containers.

Pointers are logical non-null object identifiers, not C machine addresses;
the natural-number identifier 0 is not a model of C NULL. Native address
validity and conversion into this identifier domain remain open premises.
