## WP2 bounded candidates

These choices govern only the E7C-B1/0.1 WP2 prototype and do not close the
abstract-calculus ADRs above:

| ADR | B1 candidate used for review |
|---|---|
| ADR-001 | finite immutable reusable variable lookup; no binders or consumable variables |
| ADR-002 | structural equality of canonical parsed type trees only |
| ADR-004 | finite typed effect atoms with idempotent set union for the straight-line fragment |
| ADR-005 | `total`, `strict` and `filtering` are distinct closed declaration tags; only partial variants add a partiality effect |
| ADR-011 | malformed external AST/environment is a structured checker diagnostic outside operational evaluation |

Closing an open ADR requires a focused review record stating preservation,
loss, compatibility, counterexamples and affected proofs. WP0 does not close
ADR-001–008 or ADR-011.

## WP3-S bounded candidates

These choices govern only the unimplemented E7C-B1 WP3 specification and do
not close the abstract-calculus ADRs:

| ADR | B1 WP3-S candidate used for review |
|---|---|
| ADR-003 | indexed B1 models; no universal semantic category claimed |
| ADR-004 | ordered runtime ledger; erasure to the accepted WP2 finite-set bound |
| ADR-005 | total, strict and filtering receive distinct operational clauses |
| ADR-006 | reconstruction success only after exhaustive canonical finite-fibre computation |
| ADR-007 | witness payload remains `none` pending a separate trust-boundary review |
| ADR-011 | `invalid_input` and `type_error` remain pre-operational diagnostics; outcome-typed variables are terminal bindings, while recursive value-position nesting and consumption are rejected in B1 |

WP3-S also selects deterministic big-step evaluation for the finite unary B1
fragment. Steps are charged on term entry, ledger entries immediately before
append, and candidates immediately before their canonical checks; coincident
exhaustion and semantic failure are decided by that program order. A later
concurrent or noncommuting fragment must review a labelled small-step semantics
rather than inherit this choice automatically.
