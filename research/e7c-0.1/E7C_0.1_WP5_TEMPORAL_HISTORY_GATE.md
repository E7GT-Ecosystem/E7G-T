This adapter defines an illustrative finite review/approval carrier. Its
three labelled operations and two Boolean state coordinates are **local
modelling choices**, not an executable source model or legal workflow claim.
Admitted histories carry their actual transition chain; the constructor
checks every step and operation domain. A retained final-state view keeps the
source history. A separate final-state projection states exactly what it
preserves and loses. Different histories with identical endpoints collapse
under that projection, while remaining different histories and possibly
different temporal phases.

Reconstruction searches an explicitly declared finite carrier and returns
the complete matching fibre only after scanning the carrier within a stated
bound. A resource limit has no candidate payload; an unlisted but conceivable
history is never manufactured from independent time slices. The pinned
criterion `AUDIT-APPROVAL-AND-WITHDRAWAL/0.1` groups histories by final
approval state and whether a review withdrawal occurred. Phase candidates
are computed from the **complete** fibre. A phase boundary requires an actual
admitted one-step extension. Operation order is checked in both directions;
phase-level execution checks domain saturation and result congruence on all
representatives of this declared finite carrier.

Five tests cover a shared final state with different paths and phases, source
retention versus lossy projection, finite candidate-relative completeness,
resource failure, malformed transition rejection, actual phase crossings,
noncommuting order, and a representative-dependent strict operation. Since
the source gives these rules in prose and mathematics but no corresponding
executable temporal reference, these are **specification-derived tests**, not
differential source reproduction or a metatheory proof.

No reversal of physical causation, clock simultaneity, agent knowledge,
external truth, arbitrary history-space completeness or general temporal
conformance follows. The adapter is outside the accepted E7C-B1 grammar;
the next gate is versioned typed E7C operations with operational and
denotational rules, replayable witnesses and formal correspondence. No
canonical source update, product migration or promotion is proposed.
