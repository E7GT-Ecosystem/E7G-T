The independent adapter admits a closed, finite exact-map subset with
separately typed carriers, scope editions, maps, common-codomain links and
an acyclic scope order. The source fixture's optional access, invariant,
commutation and reconstruction declarations are *not* part of this input:
tests project to the declared core before admission. Fibre and access
operations are separately requested on the admitted diagram. Unsupported
fields are rejected, so they cannot silently count as checked.

Evaluation scans a bounded product of declared scope carriers. Each link
compares the projection and lower-scope map in their shared comparison
carrier. It reports unique, ambiguous, incompatible, unsupported partial
link map or resource limit. Link-wise satisfiability and a globally
compatible family remain distinct: the parity-cycle source fixture has
all links individually satisfiable and no global assignment. A resource
limit or unsupported partial map cannot be read as incompatibility.

Candidate-relative scope-state and observation fibres are separate typed
operations; neither runs after incomplete scanning. Access classes use
the source's fixed `co_undefined_equal` rule, including the empty map
family. Differential checks compare the pinned source results for unique,
ambiguous, obstruction, unsupported and resource-limited cases, family and
link outcomes, the two fibre kinds and access quotient classes. Source
validation tests remain independent checks of the larger source language.

This is a finite profile adapter, not an E7C-B1 grammar addition or a proof
of adequacy. It omits general MSC criteria, arbitrary criterion-relative
commutation, cross-scope invariant judgments, domain authority, external
existence, and general MSC conformance. The next gate is a versioned E7C
module typing and operational/denotational correspondence for admitted
MSC operations, followed by REC in the WP5 profile order. No canonical
v0.12.1/RGP2 change or product migration is proposed.
