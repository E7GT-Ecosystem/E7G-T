# E7C/0.1 profile and module contract — WP1

Status: `wp1_vocabulary_accepted`; bounded WP5 adapter candidates have since
been integrated under separately stated source fragments and review limits.

## Required module declaration

Every profile or derived-library module must declare:

1. profile/module identity and immutable edition;
2. authority status and source pins;
3. imported modules with version constraints;
4. exported type families and their kinds;
5. exported typed operations;
6. admission predicates and domain policies;
7. terminal and extension outcomes;
8. static effect dimensions and runtime-ledger obligations;
9. exact, definitional, denotational and observational relations used;
10. positive cases, boundary/counterexamples and unsupported capabilities.

Importing a module grants none of canonical status, authority, access,
external truth, security, empirical effectiveness or product adoption.

## Adapter fidelity record

An adapter record must contain:

| Field | Required content |
|---|---|
| source | exact profile, edition, immutable pins and admitted fragment |
| target | exact E7C/module edition and target fragment |
| disposition | one permitted fidelity disposition |
| translation | total/partial mapping on source types, terms and outcomes |
| preservation | typing, admission, results, failures, identities and order preserved |
| reflection | source distinctions recoverable from target observations |
| loss/quotient | exact relation licensing any many-to-one mapping |
| rejected cases | well-formed source cases outside the translation |
| effects | static and incurred effects added/preserved/forgotten |
| witnesses | edition/source/policy pins and replay obligations |
| compatibility | positive, negative and differential fixtures |
| migration | ID, data/schema, API and consumer impact |

## Fidelity dispositions

- `faithful_embedding`: preserves and reflects the declared source relations;
  no admitted source distinction in the fragment is erased.
- `faithful_interpretation_with_explicit_loss`: preserves behaviour modulo a
  named quotient/observation family and exposes the loss.
- `partial_translation`: defines a faithful mapping only for a stated source
  subfragment and rejects the rest.
- `unsupported`: no faithful reviewed translation is currently available.

Passing examples alone cannot establish any disposition.

## Profile-specific preservation obligations

| Source | Minimum preservation boundary |
|---|---|
| EEC-Q | exact rationals, finite support, admission before cancellation, strict/total distinction and typed outcomes |
| SF | dependence, family identity, view/restrict separation, ordered realisation and empty-family distinction |
| CFS | SF-outside/EEC-inside nesting and separation of family membership from coefficients |
| RGP/0.1 RGP2 | hosting/generation/encoding/decoding/projection/inheritance/composition distinctions; independent rank/scope/time/access |
| WPC | whole/portion/occurrence/representation distinctions, constitution contract and explicit successor lineage |
| REC | support/refutation independence, provenance groups, source/model editions, scope/time/modality and policy separation |
| MSC | typed scope diagram, common comparison carrier, link/global distinction, fibres, ambiguity and obstruction |

## REC witness binding

Any later REC translation or witness must bind claim identity/content hash,
evidence polarity, source and edition, provenance/dependence group, semantic and
temporal scope, modality, rule editions, model edition, decision policy and
terminal status. Replay cannot upgrade those declarations to truth or authority.

## Composition boundary

Adapters compose only when target/source module editions match, the earlier
adapter's output lies in the latter's admitted fragment, and the combined loss,
effects, outcomes and observation relation are explicitly derived. Fidelity of
two adapters does not automatically imply fidelity of their composition.

## Review gate

This contract passes WP1 review only as a vocabulary contract. Adapter laws,
translations and proofs belong to later gated work. No profile is migrated by
this document.
