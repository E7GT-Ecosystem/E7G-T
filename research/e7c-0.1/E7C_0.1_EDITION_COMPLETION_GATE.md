# E7C edition and component completion gate (open)

Baseline: main `08c6d7b8515313ff2f6614c698f51a41fe2bb42e` (PR #109 merge).
This is an inventory and textual source audit, **not** an acceptance verdict for
the profile family. Published experimental canonical authority remains
v0.12.1/RGP2 (`a84da2c4de2ada23577cde4512a10c3369aba2b5`).
v0.13/RWP1 (`e11da3e39e6334c42f838f69fe462451f0d7c61e`) and

The source registry and manifests retain their original version identities.

## Gate rule and fidelity vocabulary

Completion requires reviewed, edition-pinned semantics for EEC-Q, SF, CFS,
RGP, WPC, MSC and REC, including each changed inherited component in v0.13
and v0.14. A row passes only with a typed rule and denotation, source-to-rule
fidelity result, bounded executable case and adversarial counterexample,
resource/failure correspondence, applicable proof or an explicitly scoped
unproved link, and independent exact-head review. An optional module needs
its **own** row. A version claiming its entire declared family is blocked
while any row is unsupported, especially WPC-Distributed/0.1. Even closing
these research gates does not automatically promote a canonical source or
product API.

`text-identical` below is only byte equality of a source section;
`bounded differential` compares selected finite models and fixtures;
`integration only` calls an existing evaluator/checker. None means an
all-input semantic preservation theorem. Every row in the last column
is an open proof or coverage obligation, including rows with examples.

## Review and execution order

1. Run `python3 research/e7c-0.1/e7c_edition_source_audit.py` against the
   exact source digests. It checks textual inheritance and identities only.
2. Close the actual Python/IR-to-Lean refinement of the selected EEC-Q
   two-stage operation with explicit encoding and resource premises.
3. For each row above, pin an edition and construct a versioned typed rule,
   finite executable witness, ordinary baseline, negative case, proof bridge
   and reviewed fidelity verdict. Prioritise the changed RGP lineage,
   WPC/0.1→/0.2 and REC rule before reusing an old adapter at a new edition.
4. Report each optional module separately and keep an unsupported row visible.
   Declare a specific supported subset if distributed operation remains out
   of scope; never call that subset full v0.13 or v0.14 coverage.

No migration of published source, product identity, data, schemas or APIs is
made by this gate. Passing CI is reproducibility evidence, not semantic
acceptance. The present E7C calculus is **incomplete** under this gate.
