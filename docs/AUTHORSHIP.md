# Project authorship

Oleksandr Razinkov is the sole named author of E7G-T. On 10 October 2026, the project owner requested that all current project author and copyright credits retain only this name. This correction includes canonical and predecessor documents, embedded reference bodies, companion code notices, citation metadata and publications.

This is an attribution correction. It changes no mathematical definitions, runtime behavior, profile identities, licenses or conformance claims. Historical Git commits, source registries and validation records retain their original immutable byte identities. Current working-tree source checks and release-manifest tables identify the corrected bytes. [The byte correction record](AUTHORSHIP_BYTES.json) distinguishes the two. Existing results remain bounded by the original evidence; this correction creates no new proof or validation claim.
